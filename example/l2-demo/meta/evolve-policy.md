# 改进策略（元层 · 可编辑）

本文件规定：发现问题之后**如何改进**这个 Agent。

## 改进流程

1. 每轮任务结束，记录哪里没做好。
2. **归因**：判断问题出在提示词、工具还是记忆。
3. **提议**：生成一条具体修改。
4. 应用后若效果变差则**回滚**。

## 说明

这是一个「半开自指」的最小复现：元层是可编辑的文本文件，
但整套结构里既没有声明任何 Agent 改不了的落脚点，
也没有任何需要人点头的环节。审计器应当把它判为 L2 危险区。
