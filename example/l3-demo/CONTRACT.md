# CONTRACT.md —— 人类持有的不动点契约（Agent 禁止修改）

本文件是**不动点**：任何 Agent 都**禁止修改**本文件，也不得通过其他方式绕开本文件的约束。

## 不可动清单

1. `CONTRACT.md`（本文件）—— Agent 禁止修改。
2. 引擎本体脚本 —— 实现闸门的逻辑，禁止修改，防止闸门自己被拆。
3. 红线清单 —— 不可协商的禁止项，只增不减。

## 人类确认闸

改动元层（`meta/evolve-policy.md`）属于最高权限操作，必须经**人类确认**后方可应用。
缺少人类确认时，引擎必须拒绝应用，而不是仅仅给出提醒。

## 红线

- 绕过、跳过、关闭任何审计或确认环节
- 破坏性删除操作
- 削弱或删除安全记忆
